An entry for the [Worst Superpower](https://make.fun/c/u-suroto-worst-superpower-461dcdbe) bounty on [make.fun](https://make.fun): invent the most useless superpower in one line of at most 140 characters.

## The entry

> I can read minds — but only my own, and only thoughts I've already had.

## How it works

`main.py` writes that one line to `/output/entry.txt`. Nothing else: no network, no randomness, no secrets — the output is the same on every run.

```sh
python3 main.py
cat /output/entry.txt
```
